# GlassNX v0.15 device acceptance checklist

Use a backed-up SD card, known working HOME override and stock clocks. Do not add any sysmodule or enable Enhanced Glass during the baseline test. Keep the existing safe-mode file mechanism and recovery manager available. Install the complete release with the console powered off.

1. Cold boot, select profile, idle for 2 minutes. Visit all six pages. Test touch and controller navigation.
2. Launch an installed game, play, press HOME, resume. Repeat 10 times. Check for screenshot ghosting, input or audio bugs, and stalled transitions.
3. Close a suspended game from HOME. Verify Resume/Close disappears and wallpaper is clean. Repeat across three games. Never interrupt saving.
4. Sleep and wake from HOME and during a game. Repeat 5 times. Check that the game still works.
5. Enable About > Performance overlay. Record 30 seconds idle HOME, 30 seconds library navigation, 30 seconds Control Center, and 30 seconds while a game is suspended. Logs record callback FPS and longest frame interval; 60 FPS / 16.7ms is a target, not verified performance.
6. Test custom system icons, all four theme files if installed, and SteamGridDB with no game running. Try invalid key, offline mode and cancellation; original artwork should remain available.
7. Only after baseline passes, repeat 1–5 with Enhanced GPU Glass enabled. If crashes occur, disable it or use Safe Mode.
8. Save the relevant /glassnx/log_uMenu.log, /glassnx/log_uSystem.log and /atmosphere/crash_reports/ or fatal_errors/ records. Note firmware, Atmosphere version, emuMMC, active sysmodules, title, action, and build identifier. Do not include API keys or personal information.

Stop and revert to the known working HOME override if Atmosphere crashes recur. Test Discord separately only after baseline is stable. A host smoke test does not validate Switch GPU behavior.

## v0.18 acceptance additions
Verify all 4 wallpaper themes and compare with the attached art pack; log must say loaded from SD wallpaper pack. Test Home, Library, Apps, Settings, Control Center, lock screen, profile selector and Artwork Studio. Exercise each native applet handoff and return. Test at stock clocks over a 30-minute session, 20 launch/HOME/resume/close cycles and 10 sleep/wake cycles, then a normal multi-hour play session. For performance overlay, capture 60 seconds per screen after warm-up; target 59–60 FPS, p95 interval near 17ms, under 1% intervals over 18ms during steady navigation; record worst stalls including network/import and page switches separately. The histogram caps the reported p95 bucket at 81ms for 80ms or greater. No device acceptance claim until console logs and observation pass. Stop on any recurring fatal error; disable HOME override using the manager or a powered-off SD backup.

## v0.20 acceptance additions
On HOME press Down and move across each dock icon; test Up/B to return to games, and Down again while dock is focused. Verify Reduce Motion (UI Motion off) and suspended-game conservative mode. Settings > Controls > Dock center shortcut: cycle all five actions, reboot and verify preference persistence; test older preferences without Dock field. HOME Y and touch Search: submit and cancel, search games/apps/folders in current folder; X system keyboard, L shift, R symbols, Y delete, + submit. Test no-results clear and library-only search. Toggle Quiet in Notifications using Y and touch; ensure saved alerts still appear. Test launch/resume/close, sleep/wake, and repeated cold boots at stock clocks before calling stable.

## v0.21 acceptance additions
Test dock animation and notification badge in all wallpapers, reduced motion, Safe Mode and while a game is suspended. With the dock focused tap the already selected title: first tap must only select, second tap opens it. Right-stick click must not open title options from the dock. Home Y: submit an empty query, search games/apps/folders, B returns Home, Y clears into Library; X edit and clear query. Test keyboard byte limit and native fallback. In Appearance, controller left/right changes each slider and persists after reboot. Verify very low battery fill (do not deliberately deep-discharge). Repeat v0.20 baseline before claiming stable.

## v0.23 native surfaces acceptance
System settings: tap all six categories, use L/R and D-pad, verify active category and first-row focus, return using visible Back and B. Enter Bluetooth paired/discover submenus, verify Back preserves cleanup and returns to category, then Home. ## v0.24 device feedback regression checks
Open advanced System Settings and Theme Studio using each wallpaper, especially 1280x720 SD images: no white strip, no cropped wallpaper, readable rows and matching Home appearance. Verify missing wallpaper fallback; verify Back and HOME, repeated entry and exit, theme switch, sleep/wake and suspended-game return. Check firmware row fits and GlassNX version reads 0.24. Search keyboard: confirm white text remains readable on selected and unselected keys, symbols, shift, cancellation and system keyboard fallback. Check storage status against actual free space (do not deliberately fill SD), and test known Sphaira forwarder names and explicit category override. If Sphaira was manually marked Game, use right-stick title options > App or Automatic. Repeat lifecycle baseline and confirm release package and build ID.

## v0.25 Game Hub acceptance
From Home and Library open Game Hub via right-stick or touch. Verify title/cover/hero/status, cancel, launch, resume, add/remove favorite, reboot persistence, classification choices and rollback on failed save. Test favorite-filter removal and app classification, changing folder or title list, suspended title, Safe Mode, no art, and artwork edit/cancel/return. Verify profile avatar and X open collection overview when no title is suspended, counts reflect existing shared environment records, Favorites and Recently Played links reset prior search, Nintendo profile handoff, and X still closes suspended games only via confirmation. Activity clear sheet defaults to Keep alerts; test B and touch cancel before confirming clear. Ensure modal inputs do not propagate to Home/Library. Repeat lifecycle and wallpaper tests from v0.24. No device acceptance claim until verified.
